---
title: "Quick Start: Send Your First Protected Transaction"
description: "Connect your wallet, set your agent policy, install the SDK, and send your first firewall-protected Solana transaction in under ten minutes."
---

<Steps>
  <Step title="Connect your wallet">
    Go to [app.prflght.xyz](https://app.prflght.xyz) and connect your Solana wallet (Phantom or Solflare). Sign the authentication message — this proves ownership of your wallet and creates your account. No password required.
  </Step>

  <Step title="Copy your API key">
    After authenticating, open the **API Keys** section of the dashboard and copy your API key. This key authorizes all firewall checks made on behalf of your agent.
  </Step>

  <Step title="Set your agent policy">
    Open the **Policy** page on the dashboard and configure your rules:

    - **Allowed programs** — select protocols your agent may interact with (Jupiter, Orca, Drift, etc.)
    - **Max notional** — maximum USDC value per transaction
    - **Daily transfer limit** — rolling 24-hour cap
    - **Deny direct transfers** — block plain SOL/SPL transfers with no DeFi interaction (recommended)

    Save the policy. Prflght applies it to every transaction your agent submits.
  </Step>

  <Step title="Install the SDK">
    <CodeGroup>

    ```bash npm
    npm install @prflght/sdk
    ```

    ```bash bun
    bun add @prflght/sdk
    ```

    </CodeGroup>
  </Step>

  <Step title="Initialize the Firewall client">
    ```typescript
    import { Firewall, FirewallDenyError } from '@prflght/sdk'

    const firewall = new Firewall({
      apiKey: process.env.PRFLGHT_API_KEY,
      // apiUrl defaults to https://api.prflght.xyz
    })
    ```

    Store your API key in an environment variable — never hardcode it.
  </Step>

  <Step title="Check your transaction before sending">
    ```typescript
    try {
      const result = await firewall.check(txBase64)
      // Prepend attestation instructions to your transaction
      const finalTx = buildTxWithIxs([...result.instructions, ...yourIxs])
      await sendAndConfirm(finalTx)
    } catch (err) {
      if (err instanceof FirewallDenyError) {
        console.error('Blocked:', err.reason)
        // e.g. "notional $15,000 exceeds policy max $10,000"
      }
    }
    ```

    <Note>
      You must prepend `result.instructions` to your transaction. The on-chain program verifies the attestation at execution time — transactions without it will fail.
    </Note>
  </Step>
</Steps>

## Environment variables

```bash
PRFLGHT_API_KEY=<your api key from the dashboard>
```
