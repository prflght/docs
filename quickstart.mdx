<Warning>
  **BYOW mode** — your agent holds its own keypair. prflght enforces policy off-chain and issues a signed on-chain attestation. The agent could bypass the SDK if compromised or prompt-injected. For production capital where hard guarantees matter, Managed Wallets (coming soon) move the key to a TEE so bypass is architecturally impossible.
</Warning>

## 1. Get your API key

1. Go to [app.prflght.xyz](https://app.prflght.xyz) and connect your Solana wallet (Phantom or Solflare).
2. Sign the authentication message — no password required.
3. Open the **API Keys** section and copy your key.

## 2. Configure your agent policy

Open the **Policy** page on the dashboard and set your rules:

- **Allowed programs** — protocol program IDs your agent may call (Jupiter, Orca, Drift, etc.)
- **Max notional** — maximum USDC value per transaction
- **Daily transfer limit** — rolling 24-hour cap
- **Deny direct transfers** — blocks plain SOL/SPL transfers with no DeFi interaction (recommended — protects against prompt injection)

Save the policy. prflght applies it to every transaction your agent submits.

## 3. Integrate — paste a prompt into your AI coding tool

Open [Cursor](https://cursor.com), [Claude Code](https://claude.ai/code), or any AI coding tool and paste the prompt for your framework:

<Tabs>
  <Tab title="Custom SDK">
    ```
    Read https://prflght.xyz/llms.txt and integrate prflght into this Solana agent.

    My API key: <PRFLGHT_API_KEY>
    My agent wallet public key: <AGENT_PUBKEY>

    Use @prflght/sdk. Add firewall.check() before every sendTransaction call.
    Prepend result.instructions to the transaction before sending.
    Throw on FirewallDenyError — do not submit blocked transactions.
    ```
  </Tab>
  <Tab title="elizaOS">
    ```
    Read https://prflght.xyz/llms.txt and integrate prflght into this elizaOS agent.

    My API key: <PRFLGHT_API_KEY>
    My agent wallet public key: <AGENT_PUBKEY>

    Install plugin-prflght. Add prflghtPlugin to the plugins array in the character config — add it last.
    Set PRFLGHT_API_KEY and PRFLGHT_AGENT_ID in .env. No other code changes needed.
    ```
  </Tab>
  <Tab title="Solana Agent Kit">
    ```
    Read https://prflght.xyz/llms.txt and integrate prflght into this Solana Agent Kit agent.

    My API key: <PRFLGHT_API_KEY>

    Install @prflght/sak-plugin. Find where SolanaAgentKit is instantiated.
    Call agent.use(new PrflghtPlugin({ apiKey: process.env.PRFLGHT_API_KEY })) immediately after.
    No other changes needed — all SAK actions are covered automatically.
    ```
  </Tab>
</Tabs>

The AI assistant reads `llms.txt`, finds the right files in your codebase, and makes the changes. No manual steps required.
