---
title: "Authenticate with Prflght Using Your Solana Wallet"
description: "Prflght uses wallet-based authentication — connect Phantom or Solflare, sign a message, and use your API key to authorize SDK requests."
---

Prflght authenticates you through your Solana wallet. There are no passwords or email-based accounts. You sign a message with your wallet to prove ownership, and the dashboard issues an API key you use to authorize all SDK calls.

## Dashboard authentication

1. Go to [app.prflght.xyz](https://app.prflght.xyz).
2. Click **Connect wallet** and select **Phantom** or **Solflare**.
3. Approve the connection in your wallet extension.
4. Sign the authentication message when prompted. The message is plain text — it does not authorize any transaction or transfer of funds.

Once signed, your session is active. Sessions persist until you disconnect your wallet from the dashboard.

## API key

Your API key is generated automatically when you first authenticate. Find it in the **API Keys** section of the dashboard.

Pass it as the `apiKey` option when initializing the SDK:

```typescript
import { Firewall } from '@prflght/sdk'

const firewall = new Firewall({
  apiKey: process.env.PRFLGHT_API_KEY,
})
```

Or set it as the `x-api-key` header when calling the API directly:

```bash
curl -X POST https://api.prflght.xyz/check \
  -H "x-api-key: $PRFLGHT_API_KEY" \
  -H "content-type: application/json" \
  -d '{"tx": "<base64 serialized transaction>"}'
```

## Environment variables

```bash
PRFLGHT_API_KEY=<your api key from the dashboard>
```

<Warning>
  Never commit your API key to source control. Store it in a `.env` file excluded from version control, or your deployment platform's secret storage.
</Warning>

## Authentication errors

If your API key is invalid or no policy is configured for your wallet, Prflght blocks the transaction and throws a `FirewallDenyError`. Check `err.reason` to distinguish authentication failures from policy violations:

```typescript
import { FirewallDenyError } from '@prflght/sdk'

try {
  const result = await firewall.check(txBase64)
} catch (err) {
  if (err instanceof FirewallDenyError) {
    console.error('Blocked:', err.reason)
  }
}
```
