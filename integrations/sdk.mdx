The `@prflght/sdk` package is the lowest-level way to integrate Prflght into any TypeScript Solana agent. Call `firewall.check()` before sending any transaction, receive attestation instructions on allow, and catch `FirewallDenyError` on deny.

## Installation

<CodeGroup>

```bash npm
npm install @prflght/sdk
```

```bash bun
bun add @prflght/sdk
```

</CodeGroup>

## Initialization

```typescript
import { Firewall, FirewallDenyError } from '@prflght/sdk'

const firewall = new Firewall({
  apiKey: process.env.PRFLGHT_API_KEY,
  agentId: agentKeypair.publicKey.toBase58(), // your agent's wallet public key
  // apiUrl is optional - defaults to https://api.prflght.xyz
})
```

## Checking a transaction

Call `firewall.check()` before sending any transaction. Pass the transaction serialized to base64.

```typescript
// Serialize your transaction to base64
const txBase64 = Buffer.from(tx.serialize()).toString('base64')

try {
  const result = await firewall.check(txBase64)
  // Prepend attestation instructions before your own
  const finalTx = buildTxWithIxs([...result.instructions, ...yourIxs])
  await sendAndConfirm(finalTx)
} catch (err) {
  if (err instanceof FirewallDenyError) {
    console.error('Blocked:', err.reason)
  } else {
    throw err
  }
}
```

<Note>
  You must prepend `result.instructions` to your transaction. The on-chain program verifies the attestation at execution time - submitting without it will cause the transaction to fail.
</Note>

## Error handling

`FirewallDenyError` is thrown whenever Prflght blocks a transaction.

| Property | Type | Description |
|---|---|---|
| `err.reason` | `string` | Human-readable explanation of why the transaction was denied |

Common reason strings:

- `"notional $X exceeds policy max $Y"` - transaction value exceeds your per-tx cap
- `"program not in allowlist: <pubkey>"` - the transaction calls a program not in your policy
- `"protocol health check failed"` - a protocol involved has a health score below your threshold
- `"direct wallet transfer blocked"` - `deny_direct_transfers` is enabled and no DeFi program is invoked
- `"No policy configured"` - no policy found for your API key owner wallet

## Environment variables

```bash
PRFLGHT_API_KEY=<your api key from the dashboard>
```
