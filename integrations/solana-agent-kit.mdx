The `@prflght/sak-plugin` package adds Prflght firewall protection to any agent built with [Solana Agent Kit](https://github.com/sendaifun/solana-agent-kit). After a one-line setup call, every SAK action that produces a transaction is automatically intercepted and checked against your policy before it reaches the chain.

## Installation

```bash
npm install @prflght/sak-plugin
```

## Setup

<Steps>
  <Step title="Set environment variables">
    ```bash
    PRFLGHT_API_KEY=<your api key from app.prflght.xyz>
    SOLANA_PRIVATE_KEY=<your agent's base58 keypair>
    SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
    ```
  </Step>

  <Step title="Register the plugin">
    ```typescript
    import { SolanaAgentKit } from 'solana-agent-kit'
    import { PrfghtPlugin } from '@prflght/sak-plugin'

    const agent = new SolanaAgentKit(
      process.env.SOLANA_PRIVATE_KEY,
      process.env.SOLANA_RPC_URL,
      { OPENAI_API_KEY: process.env.OPENAI_API_KEY },
    )

    agent.use(new PrfghtPlugin({
      apiKey: process.env.PRFLGHT_API_KEY,
    }))
    ```
  </Step>

  <Step title="Run your agent normally">
    All transactions produced by any SAK action are now automatically protected by Prflght. No changes to action code required.
  </Step>
</Steps>

<Note>
  The plugin intercepts at the SAK level, so every action — including ones you add later — is covered automatically.
</Note>

## How it works

SAK actions (swaps, transfers, liquidity provision, etc.) all go through a shared transaction submission path. `PrfghtPlugin` hooks into that path to intercept every transaction and call `POST /check` before submission.

If the transaction passes your policy, Prflght returns attestation instructions that are automatically prepended to the transaction. If it fails, the action throws with the deny reason.

## Comparison

| | `@prflght/sak-plugin` | `@prflght/sdk` |
|---|---|---|
| **Setup** | One `agent.use()` call | Manual `firewall.check()` before each tx |
| **Coverage** | All SAK actions automatically | Only where you call `check()` |
| **Best for** | SAK-based agents | Custom agents or non-SAK frameworks |
